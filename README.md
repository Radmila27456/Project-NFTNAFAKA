# Project-NFTNAFAKA

Povijesni prototip alternativnog web sučelja za [NFTNAFAKA](https://github.com/Radmila27456/NFTNAFAKA). Ovo nije zasebna NFT kolekcija.

## Status

`index.html` je javna informativna stranica. Mintanje je isključeno dok se ne usklade ugovor, ABI, mreža, IPFS podaci i SFT nagrade. Stari kod u `app.js` i `abi.js` ostaje u repozitoriju kao razvojni materijal i **nije povezan s aktivnom stranicom**.

Prototip iz 2025. spominjao je BNB Smart Chain, 0,05 BNB i 100 SFT po NFT-u. To nisu trenutačno potvrđeni uvjeti javnog mintanja. Točnu mrežu i stanje objavljenog ugovora treba provjeriti prije ponovnog puštanja transakcija.

## Datoteke

- `index.html` — aktivna prezentacija
- `app.js`, `abi.js`, `style.css` — neaktivni raniji dijelovi prototipa

Za izvornu dokumentaciju kolekcije i popis preostalih provjera pogledajte [glavni README](https://github.com/Radmila27456/NFTNAFAKA#readme). Projekt tokenizacije nekretnina je zaseban.
